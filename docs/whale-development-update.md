## MTAA 当前状态

MTAA 是独立的比赛 Demo：群消息与人物为虚构数据，记忆放在浏览器 `localStorage`，使用 `lib/memory.js` 等演示逻辑。它**尚未连接** Whale 核心项目的群记忆数据库、画像服务、图谱 API 或真实 QQ 消息。MTAA 中显示的记忆结果不能当作 PR #95 的端到端运行结果。

后续若要接入真实 Whale，优先实现一个经过身份验证的只读接口：按群获取记忆、画像、关键词及其证据；再让 MTAA 服务端转发请求。不要把聊天导出文件、成员账号、原始画像、数据库或 API 密钥提交到这个公开仓库。
